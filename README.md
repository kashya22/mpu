Insomnia Care — Traditional Chinese Medicine Treatment Platform

Project Description:
Insomnia Care is a web-based platform designed to help individuals suffering from insomnia connect with certified Traditional Chinese Medicine (TCM) doctors. The website provides an easy-to-use interface where patients can learn about insomnia, explore natural treatment methods based on TCM, and book online consultations with practitioners.

This project aims to combine the wisdom of ancient Chinese healing techniques with the convenience of modern web technology, offering patients a holistic and accessible approach to improving their sleep health.

Frontend: HTML, CSS, JavaScript
Backend:   PHP
